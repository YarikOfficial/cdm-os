# ZachetOS / cdm-os

Учебная мини-операционная система для процессора **CdM-16** в **Logisim**.

Проект демонстрирует базовые механизмы ОС:

- обработку прерываний;
- ввод с клавиатуры;
- вывод в терминал;
- командную оболочку shell;
- запуск пользовательских программ;
- библиотечные функции;
- таймер;
- простой диспетчер фоновых задач.

---

## Возможности

В системе реализованы:

- запуск ядра через таблицу векторов прерываний;
- обработчик клавиатуры;
- терминальный ввод/вывод;
- shell с приглашением `>`;
- таблица программ;
- запуск программ по имени;
- ввод строки от пользователя;
- перевод строки в число;
- перевод числа в строку;
- программа `input`;
- программа `calc`;
- таймер;
- кооперативный диспетчер фоновых задач;
- команды мониторинга задач `ps` и `tasks`.

---

## Команды

| Команда | Назначение |
|---|---|
| `ls` | показать список доступных программ |
| `prog1` | запустить программу 1 в обычном режиме |
| `prog2` | запустить программу 2 в обычном режиме |
| `input` | проверить ввод строки |
| `calc` | запустить простой калькулятор |
| `prog1bg` | запустить `prog1` как фоновую задачу |
| `prog2bg` | запустить `prog2` как фоновую задачу |
| `kill1` | остановить фоновую задачу `prog1` |
| `kill2` | остановить фоновую задачу `prog2` |
| `ps` | показать состояние фоновых задач |
| `tasks` | показать состояние фоновых задач |

## Сборка

Из папки проекта:

```bash
cd src
cocas *.asm -t cdm16
```

После сборки полученный образ нужно загрузить в память процессора в Logisim.

---

## Запуск в Logisim

1. Открыть схему проекта в Logisim.
2. Найти блок памяти RAM.
3. Через контекстное меню памяти загрузить собранный образ.
4. Запустить симуляцию.
5. Перейти к терминалу.
6. Вводить команды после символа `>`.

Пример:

```text
>ls
>calc
>prog1bg
>ps
```

## Диспетчер задач

В проект добавлен простой кооперативный диспетчер фоновых задач.

Он умеет:

- запускать фоновые задачи;
- останавливать фоновые задачи;
- хранить состояние `RUN` / `STOP`;
- считать количество тиков задачи;
- показывать состояние через `ps` и `tasks`.

Таймер не переключает процессы напрямую. Он выставляет флаг системного тика, после чего диспетчер выполняет один маленький шаг активной фоновой задачи.

Фоновые задачи не могут напрямую писать в терминал и читать клавиатуру, чтобы не мешать работе shell.
