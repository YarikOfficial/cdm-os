# Краткое описание файлов и функций

## kernel_main.asm

Файл отвечает за запуск ядра, обработку прерываний, клавиатуру, таймер и запуск команд.

### Interrupt Vector Table

Таблица векторов прерываний.  
Хранит адреса обработчиков: запуск ядра, ошибки, клавиатура, таймер, syscall.

### default_handler

Обработчик неизвестных или ошибочных прерываний.  
Останавливает процессор через `halt`.

### syscall_handler

Обработчик системного вызова.  
Сейчас просто возвращает управление через `rti`.

### tim_handler

Обработчик таймера.  
Используется для системных тиков. В новой версии выставляет флаг для диспетчера задач.

### key_handler

Обработчик клавиатуры.  
Считывает символ с клавиатуры, сохраняет его в `kb_buffer`, обрабатывает Backspace и Enter.

### kb_buffer

Общий буфер клавиатуры.  
В него записывается строка, которую вводит пользователь.

### kb_tail

Позиция следующего символа в `kb_buffer`.  
Нужна, чтобы знать, куда записывать новый символ.

### kb_line_ready

Флаг готовности строки.  
Если равен `1`, значит пользователь нажал Enter и строка готова для чтения.

### key_execute_command

Функция запуска команды.  
Берёт строку пользователя, ищет её в таблице программ `fs_table` и запускает найденную программу.

### kernel_main

Точка входа в ядро.  
Настраивает стек и передаёт управление в `os_main`.

### sched_tick_count

Общий счётчик тиков таймера.  
Показывает, сколько раз сработал таймер.

### sched_tick_pending

Флаг тика для диспетчера.  
Если равен `1`, значит диспетчер должен выполнить один шаг фоновой задачи.

### sched_current_task

Номер текущей выполняемой задачи.  
`0` — shell или обычная программа, не `0` — фоновая задача.

### sched_task1_state

Состояние фоновой задачи `prog1`.  
`RUN` — работает, `STOP` — остановлена.

### sched_task2_state

Состояние фоновой задачи `prog2`.  
`RUN` — работает, `STOP` — остановлена.

### sched_task1_ticks

Количество тиков, которые получила фоновая задача `prog1`.

### sched_task2_ticks

Количество тиков, которые получила фоновая задача `prog2`.

### sched_start_task1

Запускает фоновую задачу `prog1`.

### sched_stop_task1

Останавливает фоновую задачу `prog1`.

### sched_start_task2

Запускает фоновую задачу `prog2`.

### sched_stop_task2

Останавливает фоновую задачу `prog2`.

### task_dispatch_once

Один шаг диспетчера задач.  
Проверяет флаг таймера, выбирает активную задачу и запускает её маленький step.

## kernel_drivers.asm

Файл содержит драйвер терминала.

### kernel_driver_tty_enable

Включает терминал.  
Записывает значение в управляющий порт терминала.

### kernel_driver_tty_print

Печатает строку в терминал.  
Получает адрес строки в `r0`, выводит символы по одному до нулевого байта.

В новой версии также защищает shell: если печать пытается выполнить фоновая задача, вывод блокируется.

## os_main.asm

Файл содержит главный цикл командной оболочки.

### command_buffer

Буфер для команды пользователя.  
Сюда записывается строка, введённая после символа `>`.

### os_main

Главная функция ОС.  
Включает терминал, выводит приветствие, включает прерывания и запускает бесконечный shell loop.

### shell_loop

Основной цикл shell.  
Печатает приглашение `>`, читает команду через `os_lib_gets`, запускает её через `key_execute_command` и снова ждёт следующую команду.

## os_lib.asm

Файл содержит библиотечные функции ОС.

### os_lib_strlen

Считает длину строки.  
Проходит по символам до нулевого байта и возвращает длину в `r1`.

### os_lib_strcmp

Сравнивает две строки.  
Возвращает `0`, если строки одинаковые, и `1`, если разные.

### os_lib_gets

Читает строку пользователя.  
Ждёт, пока клавиатура подготовит строку, затем копирует её из `kb_buffer` в буфер программы.

В новой версии также вызывает диспетчер задач после `wait`, чтобы фоновые задачи могли выполняться во время ожидания ввода.

### os_lib_atoi

Переводит строку в число.  
Например, строку `"123"` превращает в число `123`.

### os_lib_itoa_u16

Переводит число в строку.  
Например, число `42` превращает в строку `"42"`.

## os_strings.asm

Файл содержит строки, которые выводятся в терминал.

### os_string_greeting

Приветствие ОС при запуске.

### os_string_prompt_start

Строка приглашения shell.  
Обычно это символ `>`.

### os_string_help

Текст со списком доступных команд.

### os_string_ls

Список программ для команды `ls`.

### os_string_prog1

Сообщение программы `prog1`.

### os_string_prog2

Сообщение программы `prog2`.

### os_string_error_invalid_command

Сообщение об ошибке, если пользователь ввёл неизвестную команду.

### os_string_input_ask

Сообщение перед вводом строки в программе `input`.

### os_string_input_ans

Сообщение перед выводом введённой строки в программе `input`.

### os_string_calc_a

Приглашение ввести первое число для `calc`.

### os_string_calc_b

Приглашение ввести второе число для `calc`.

### os_string_calc_result

Текст перед выводом результата калькулятора.

### os_string_newline

Перевод строки.

### os_string_prog1bg_started

Сообщение о запуске `prog1` в фоне.

### os_string_prog2bg_started

Сообщение о запуске `prog2` в фоне.

### os_string_prog1bg_stopped

Сообщение об остановке фоновой задачи `prog1`.

### os_string_prog2bg_stopped

Сообщение об остановке фоновой задачи `prog2`.

### os_string_ps_header

Заголовок таблицы задач для команд `ps` и `tasks`.

## programs.asm

Файл содержит таблицу программ и код пользовательских программ.

### fs_table

Таблица программ.  
Хранит пары: имя команды и адрес функции программы.

### prog1

Обычная программа `prog1`.  
Выводит сообщение или показывает результат работы фоновой версии `prog1`.

### prog2

Обычная программа `prog2`.  
Выводит сообщение или показывает результат работы фоновой версии `prog2`.

### program_ls

Команда `ls`.  
Печатает список доступных программ.

### program_input

Команда `input`.  
Просит пользователя ввести строку и выводит её обратно.

### program_calc

Команда `calc`.  
Запрашивает два числа, переводит строки в числа, складывает их и выводит результат.

### program_prog1bg

Команда `prog1bg`.  
Запускает `prog1` как фоновую задачу.

### program_prog2bg

Команда `prog2bg`.  
Запускает `prog2` как фоновую задачу.

### program_kill1

Команда `kill1`.  
Останавливает фоновую задачу `prog1`.

### program_kill2

Команда `kill2`.  
Останавливает фоновую задачу `prog2`.

### program_ps

Команда `ps` / `tasks`.  
Выводит таблицу фоновых задач: PID, имя, состояние и количество тиков.

### prog1_background_step

Один маленький шаг фоновой задачи `prog1`.  
Выполняет минимальную работу, например увеличивает счётчик, и сразу возвращает управление системе.

### prog2_background_step

Один маленький шаг фоновой задачи `prog2`.  
Выполняет минимальную работу, например увеличивает свою переменную, и сразу возвращает управление системе.

### input_buffer

Буфер для программы `input`.

### calc_buf_a

Буфер для первого числа в программе `calc`.

### calc_buf_b

Буфер для второго числа в программе `calc`.

### calc_result_buf

Буфер для результата программы `calc`.
